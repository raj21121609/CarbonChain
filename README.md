## 🌟 The Vision

CarbonChain is built to be the operating system for global sustainability. We bridge the gap between enterprise ESG (Environmental, Social, and Governance) commitments and verifiable blockchain technology. 

By leveraging the **Base** network and abstracting away the friction of crypto wallets through our Universal Gasless Forwarder (UGF), we allow organizations to mint and verify their carbon reduction metrics instantly, immutably, and—most importantly—with **zero gas fees**.

---

## ✨ Key Features

- **🛡️ Immutable ESG Records:** Mint verifiable ESG credentials as secure ERC721 tokens on the blockchain. 
- **⛽ Gasless Execution (UGF):** Enterprises don't need to hold crypto to participate. Our Universal Gasless Forwarder handles transaction sponsorship automatically.
- **⚡ Cinematic, Real-Time UI:** Built with React, Framer Motion, and TailwindCSS for a breathtaking, highly responsive 3D visualization of global sustainability efforts.
- **📊 Live Telemetry:** Monitor sponsored gas pools, active relayers, and on-chain indexer metrics directly from the dashboard.
- **🔒 Enterprise-Grade Security:** Audited smart contract architecture deployed on Base Sepolia ensuring total data integrity.

## 🛠️ Technology Stack

### Frontend & UI
- **React.js (Vite)** - Lightning-fast UI rendering
- **Tailwind CSS** - Utility-first, responsive styling
- **Framer Motion** - Fluid, cinematic animations and micro-interactions
- **Lucide React** - Clean, modern iconography

### Blockchain & Web3
- **Base Sepolia** - Fast, secure, scalable L2 infrastructure
- **Wagmi & Viem** - Robust Ethereum interaction hooks
- **Solidity** - Custom ERC721 smart contracts for ESG Credentials
- **Meta-Transactions (EIP-712)** - Enabling our Universal Gasless Forwarder

## 🚀 Getting Started

Follow these instructions to run the CarbonChain UI locally:

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-repo/carbonchain.git
   cd carbonchain
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   Create a `.env` file in the root directory and configure your Web3 provider keys.

4. **Run the development server**
   ```bash
   npm run dev
   ```
   *The application will be available at `http://localhost:5173`.*
